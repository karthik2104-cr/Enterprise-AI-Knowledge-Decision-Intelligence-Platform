# IT Security Policy (DEMO / SAMPLE DATA)

Northwind Analytics Group — Information Security
Synthetic demonstration content.

## Access control
Access follows least privilege. Production access requires a ticket, manager approval, and MFA. Shared passwords are forbidden.

## Authentication
SSO is mandatory for corporate applications. Passwords, where required, must be at least 14 characters. Hardware keys are required for administrators.

## Device security
Full-disk encryption is required. Unmanaged devices may not store customer data. Lost devices must be reported within four hours.

## Data classification
Public, Internal, Confidential, and Restricted. Restricted data (customer production extracts, credentials) cannot be copied to personal cloud storage.

## Software
Only approved software may be installed. Browser extensions that read page content are prohibited.

## Incident response
Severity 1 incidents are declared when customer data may be exposed. The on-call security engineer must be paged and Legal notified within 1 hour.
